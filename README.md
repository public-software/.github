# public-software/.github

Organization defaults for Public Software: the profile README, the reusable workflows every repository
calls, the community health files, the issue and pull request templates, the label source and the brand.
Generated by the bootstrap kit — edit there, not here.

## Reusable workflows

| Workflow | Called from | What it does |
|---|---|---|
| `rust.yml` | `ci.yml` in every repository, on push, pull_request and merge_group | skeleton and naming check, then test / doc / deny / semver once the repository has a crate |
| `mirror.yml` | `mirror.yml` in every repository, when `FORGE_MIRROR_URL` is set | push-mirrors every branch and tag to the forge |

Both are versioned as **immutable releases** of this repository. Callers pin the release commit:

```yaml
uses: public-software/.github/.github/workflows/rust.yml@<sha> # v1.0.0
```

`v1.0.0` is the current release. The tag `v1` (the major) always points at the newest `v1.x.y`
release commit and exists for humans reading the history; it is never itself released, so it can move.

Every third-party action in these workflows is pinned to a full commit SHA with its version as a comment.
Dependabot (`.github/dependabot.yml`, `github-actions` ecosystem) bumps the SHA and the comment together,
here and in every repository that pins a release of this one.

## Bumping the workflows

1. Change a workflow in the bootstrap kit (`templates/dotgithub/.github/workflows/`).
2. Set `WORKFLOWS_VERSION` in `config/org.env` to the next version: patch for a pin bump, minor for a new
   job or input, major when a check-run name or an input changes meaning.
3. Run `./bootstrap.sh 04`. The kit pushes the change, publishes the immutable release at that commit and
   moves the major tag; a release that already exists is left alone (an immutable release cannot change).
4. Repositories follow through Dependabot; `./bootstrap.sh 05` renders new repositories against the new
   release from day one.

## Linting

`lint.yml` runs [zizmor](https://docs.zizmor.sh) in the pedantic persona and
[actionlint](https://github.com/rhysd/actionlint) on every push and pull request of this repository.
