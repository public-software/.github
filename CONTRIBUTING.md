# Contributing to Public Software

1. Every repository looks the same; `pub check` tells you if yours drifts.
2. Reimplement from specifications, conformance suites and documentation. Cite permissively licensed references for behaviour. Do not read copyleft implementations of the module you are writing; record what you consulted in `PROVENANCE.md`.
3. Cross-repository or interface changes need an RFC in `public-software/rfcs`. Repo-local design goes in `docs/adr/`.
4. Sign off commits (DCO) and sign them. Squash merges use the PR title as a conventional commit.
5. Licence: `Apache-2.0 OR MIT` for code, CC-BY-4.0 for specs and content. No CLA.
